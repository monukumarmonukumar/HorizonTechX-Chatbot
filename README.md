# HorizonTechX-Chatbot

A simple rule-based chatbot built in Python for Horizon Company Internship - Task 1.

This chatbot interacts with the user via terminal and responds to basic greetings and questions.

## 🚀 Features
- Greets user with Hi / Hello
- Responds to "how are you"
- Tells its own name / introduction
- Exits gracefully when user types "bye"
- Case-insensitive input handling using .lower()

## 🛠️ Tech Stack
- Python 3.x
- No external libraries required (Pure Python)

## How to Run This Chatbot

1. First download or clone this project
2. Make sure Python is installed on your computer
3. Open the file `chatbot.py` in any code editor or terminal
4. Run the file using: python chatbot.py
5. Chat with the bot. Type 'bye' to exit.

## What This Bot Can Do

- Say hi / hello -> Bot will reply Hi!
- Ask how are you -> Bot will reply I'm fine
- Ask what is your name -> Bot will introduce itself
- Type bye -> Bot will say Goodbye and exit
